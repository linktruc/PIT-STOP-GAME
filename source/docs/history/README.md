# Historical version notes

These markdown files preserve earlier deployment/test descriptions for context. They are not current acceptance or upgrade instructions. Use the root `V10_3_DEPLOY_GUIDE.md`, `TEST_REPORT.md` and `V10_3_CHANGELOG.md`.

Full V8/V9 evidence folders are preserved in their original version ZIPs and excluded from the V10 source ZIP to avoid duplicating large screenshot sets. The V10 package includes its complete new evidence and three actual V9 baseline captures under `docs/v10-evidence/`. Links in unchanged historical notes may refer to those original-version evidence folders.
